## 📖 دربارهٔ پروژه

**MigrationHunter** یک سیستم هوشمند مهاجرت است که:

- 🔍 به‌صورت خودکار در سایت‌های کاریابی جهانی جستجو می‌کند
- 🎓 برنامه‌های تحصیلی را پیدا می‌کند و اپلیکیشن‌ها را تا پذیرش پیگیری می‌کند
- 🛂 مراحل ویزا را چک‌لیست می‌کند و هر اقدام را با تاریخ ثبت می‌کند
- 🤖 از API هوش مصنوعی (OpenAI/Gemini) برای تحلیل هوشمند استفاده می‌کند
- 🎯 فرصت‌ها را بر اساس پروفایل متقاضی رتبه‌بندی می‌کند
- 📊 داشبورد اکسل با نمودارها و قالب‌بندی شرطی تولید می‌کند
- 📧 نامه‌های پوش و ایمیل‌های درخواست شخصی‌سازی شده ایجاد می‌کند
- 🧠 از جستجوهای قبلی یاد می‌گیرد و منابع موفق را رتبه‌بندی می‌کند

**هدف نهایی:**

```
کار یا تحصیل → پذیرش → ویزای قانونی → مهاجرت قانونی → مهاجرت خانوادگی
```

## 🔄 چه چیز در v4.0 تغییر کرد

| قبل | بعد |
|------|------|
| فقط کاریابی | دو مسیر جدا **کاریابی** و **تحصیل** با انتخابگر در کل داشبورد |
| progress فقط روی منبع | **روی تک‌تک آدرس** — جدول زندهٔ نام سایت · لینک · کلیدواژه · تعداد · زمان · وضعیت |
| هیچ پیگیری تحصیلی | **بانک اپلیکیشن** با ۷ وضعیت (در نظر → ارسال → پذیرش → ثبت‌نام) + تاریخچه |
| مدرک و سفارت گم می‌شد | **نورد ویزا**: چک‌لیست ۲۰ مرحله + دفترچهٔ اکت‌ها + هشدار کارهای بی‌تیک |
| منابع تحصیلی در کد بودند | منابع هر دو مسیر در `sources.json` (۶۸ منبع، ۲۰ کشور) |
| «مرده» در validator یعنی HTTP ساده | validator با **مرورگر headless** — ۳۱۹ یافته در فنلاند |
| Chromium بلاک می‌شد | fallback خودکار به **Edge ویندوز** (بدون دانلود) |

## 🔄 چه چیز در v3.1 تغییر کرد

| قبل | بعد |
|------|------|
| سایت‌های JS-only (Seek، Indeed…) همیشه صفر | مرورگر headless (Edge/Chromium) — بدون نصب اضافه روی ویندوز |
| هیچ آماری از کدام سایت آگهی می‌دهد | تب «📈 بازده منابع» — جدول بازده هر سایت در طول زمان |
| اسکنر کشف، هر دامنه‌ای را می‌گرفت | تأیید دومرحله‌ای — فقط دامنه‌هایی که واقعاً آگهی دارند ثبت می‌شوند |
| `Session expired` به‌جای نام شرکت | تشخیص عنوان≠شرکت — شرکت نامعتبر حذف می‌شود |
| لیست منابع هاردکد در کد | مرجع واحد: `sources.json` — بدون هاردکد |
| نام شرکت همیشه «نامشخص» | استخراج واقعی از JSON-LD + h2/h3 اطراف لینک |
| فایل‌ها صفحهٔ اصلی را شلوغ می‌کردند | تب اختصاصی «📁 فایل‌ها» + صفحهٔ اصلی = گزارش زنده |
| هیچ حافظه‌ای از منابع موفق | بانک `discovered_sources.json` — منابع پربازده اول جستجو |

## 🏗️ معماری سیستم

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│  جمع‌آوری       │ →  │  تحلیل AI       │ →  │  خروجی          │
│  (وب اسکرپر)    │    │  (تحلیلگر شغل)  │    │  (اکسل + MD)    │
└─────────────────┘    └──────────────────┘    └─────────────────┘
        ↓                       ↓                       ↓
   ┌─────────┐           ┌──────────┐           ┌──────────┐
   │Requests │           │امتیازدهی │           │openpyxl  │
   │BeautifulSoup│      │ تطبیق    │           │Markdown  │
   │تحلیل HTML│        │یادگیری   │           │گزارش‌ها  │
   └─────────┘           └──────────┘           └──────────┘
```

### سه لایه اصلی

| لایه | عملکرد | ابزارها |
|-------|----------|---------|
| **جمع‌آوری** | خواندن سایت‌ها، استخراج JSON-LD (schema.org/JobPosting) و لینک‌های آگهی؛ رندر JS با Playwright/Edge برای سایت‌های JS-only | Python (urllib + HTMLParser + Playwright) |
| **تحلیل** | امتیازدهی، تطبیق، یادگیری | Python + AI API (OpenAI/Gemini) |
| **خروجی** | اکسل + گزارش‌های فارسی + ایمیل | openpyxl + Markdown + SMTP |

## 🧲 بانک منابع خودآموخته (جدید در v3.1)

فایل `memory/discovered_sources.json` — قلب سیستم یادگیری منابع:

- **قبل از هر جستجو:** صفحهٔ منابع اسکن می‌شود و دامنه‌های «آگهی‌دار» جدید (تا ۱۲ در هر اجرا) کشف و ثبت می‌شوند
- **حین جستجو:** هر سایتی که آگهی واقعی داد، در بانک ثبت می‌شود (`total_found`، `hits`)
- **اجرای بعدی:** منابع اثبات‌شده بر اساس بازده به‌صورت خودکار **اول جستجو** می‌شوند
- **بدون دست‌زدن به sources.json** — لیست اصلی شما محفوظ می‌ماند

```json
{
  "Job Bank Canada (رسمی دولت)": {
    "url": "https://www.jobbank.gc.ca",
    "country": "CA",
    "total_found": 47,
    "hits": 3,
    "last_seen": "2026-09-17 14:30"
  }
}
```

## 👥 پروفایل متقاضیان (پویا)

اجرای `python setup.py` برای ایجاد پروفایل‌ها. هر متقاضی شامل موارد زیر است:

- **نام** (انگلیسی + فارسی)
- **حرفه** و **کلمات کلیدی** (تولید خودکار)
- **جنسیت** (برای ایموجی/رنگ)
- **سطوح زبان** (انگلیسی، آلمانی)
- **ایمیل‌های متعدد** (هر کدام با رمز عبور اپلیکیشن)
- **پروفایل‌های لینکدین متعدد**

## 📋 قوانین اصلی

### قاعده زبان — جستجو هرگز متوقف نمی‌شود

```
❌ قدیم: "بدون آیلتس ۷ → رد فرصت"
✅ جدید: "ردیابی فرصت → زبان = مرحله تأیید"
```

**زبان یک پیش‌فیلتر نیست.** فقط یک مرحله تأیید نهایی است.

### بدون جعل اطلاعات

- هرگز شغل جعلی ایجاد نکنید
- اگر مشخص نیست: **نامشخص** درج کنید
- اولویت با منابع رسمی و کارفرمایان واقعی

### بدون حذف حافظه

- تاریخچه حذف نمی‌شود
- اطلاعات قدیمی علامت‌گذاری: منقضی / قدیمی

### محافظت در برابر کلاهبرداری

فوراً پرچم بزنید:
- پیشنهادات شغلی تضمینی
- ویزاهای تضمینی
- پرداخت برای پیشنهاد شغلی
- ارتباط فقط از طریق WhatsApp/Telegram
- فشار برای پرداخت اولیه

## 📊 داشبورد اصلی (۱۳ برگه)

| برگه | عنوان | محتوا |
|-------|-------|---------|
| ۰۱ | **داشبورد** | کارت‌های KPI، تفکیک کشور/متقاضی، ۵ برتر |

| ۰۷ | **درخواست‌ها** | پیگیری خط لوله درخواست‌ها |
| ۰۸ | **پیگیری** | پیگیری ۷ روزه |
| ۰۹ | **ویزا** | الزامات ویزا بر هر کشور |
| ۱۰ | **ثبت‌نام** | مسیرهای ثبت‌نام حرفه‌ای |
| ۱۱ | **مدرک** | ماتریکس امتیازدهی مدارک |
| ۱۲ | **تاریخچه** | گزارش تاریخچه جستجو |
| ۱۳ | **تحلیل ایمیل** | آمار دسته‌بندی ایمیل‌ها |

### قالب‌بندی

- **فونت‌ها:** B Mitra (فارسی) + Times New Roman (انگلیسی)
- **جهت:** راست به چپ (RTL)
- **قالب‌بندی شرطی:** سبز/زرد/قرمز بر اساس تصمیم
- **فیکس پن‌ها:** هدرها همیشه مشاهده می‌شوند
- **فیلتر خودکار:** تمام جدول‌ها قابل فیلتر هستند
