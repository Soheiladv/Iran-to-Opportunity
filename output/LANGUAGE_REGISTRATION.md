## مسیرهای زبان مورد نیاز

### 👩 ندا — OET / IELTS

**OET = Occupational English Test**

| فیلد | مقدار |
|------|-------|
| Test | OET (Occupational English Test) |
| Purpose | Professional registration for healthcare |
| Accepted By | Midwifery Council NZ, AHPRA, NMC |
| Required Score | B in each sub-test |
| Cost | AUD $587 / USD $455 |
| Duration | 3.5 hours |
| Sub-tests | Listening, Reading, Writing, Speaking |
| Preparation | 3-6 months recommended |
| Resources | https://www.oet.com |

**IELTS Academic** (alternative):

| فیلد | مقدار |
|------|-------|
| Test | IELTS Academic |
| Required Score | 7.0 each band |
| Cost | $215-250 USD |
| Resources | British Council, IDP |

**نکته مهم:**
- OET و IELTS هر دو پذیرفته می‌شوند
- OET برای حرفه‌های سلامت مناسب‌تر است
- آمادگی همزمان با جستجوی کار انجام شود
